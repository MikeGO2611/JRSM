# Componentes
Clases que se usen en varias partes del código.

## Menú
Para mostrar las opciones del menú, al igual que los submenús.
Requerimientos:
 - Ha de admitir n cantidad de parámetros que mostrar.
 - Ha de poder mostrar la opción de pulsar 0 para volver al menú anterior.

## Conexión con la base de datos
El programa ha de contactar con la base de datos para guardar y recibir información, como al conseguir un tesoro, acabar una expedición o mostrar cualquier información, como habilidades o tesoros.
